Enlaces

Los enlaces son de gran importancia en el desarrollo de una pagina web, ya que puede enlazar con otras paginas, utilizando su vinculo o url. Ayuda a anclar y nunca cambiara a menos que se le cambie la direccion del vinculo esperado.

Primeros toques con un enlace

De lo anterior, nace el nombre a la etiqueta de un vinculo, la cual seria a de ancle en ingles o en español ancla, ya que se sostiene y nunca se rompe a la hora de utilizar un link

Teniendo en cuenta, lo anterior ela etiqueta en si es: 

        
            <a></a>
Pero a la hora de utilizarla se necesitaran unos atributos los cuales le daran la magia al enlace o al link.
El primer atributo del cual se nombrara es href, el cual permite enlazar nuestra pagina con otra. Para que este funcione es fundamental utilizar las comillas dobles despues de llamarlo.

Como utilizarlo?
        
            <a href="https://youtube.com"></a>
